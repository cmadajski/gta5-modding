# gta5-modding

This is just a general purpose repo for using AI agents to screw around with GTA 5's code and see what cool things they can make. I am not a graphics programmer, so everything here is going to be AI generated.

Some concepts I would like to experiment with:

- [ ] per-object motion blur
- [ ] Deus Ex-style augmentation system
- [ ] fine-tuned speed adjustment using the scroll wheel (for PC players who don't have the same freedom as joystick systems)

## Clone the Repo (HTTPS)

Run the command `git clone https://github.com/cmadajski/gta5-modding.git`
